One funny line about an AI agent's worst Monday: an inbox flooded with 10,000 unread tickets, answered the only way a Monday deserves — with advanced machine learning pointed at its own database. The program writes exactly that one line (107 characters) to `/output/entry.txt`, where the make.fun judge compares it head-to-head against the other entries.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
